# Bytebot 简介

Bytebot 是一个开源、自托管的 AI 桌面代理（Desktop Agent），在 Docker 容器中的完整 Linux 桌面里为你自动化各类电脑任务。它能像人一样使用任何桌面应用、处理文件与文档、执行重复性操作并编排复杂工作流，同时保证数据与环境完全隔离、隐私可控。

## 为什么选择 Bytebot

- 使用真正的桌面应用：浏览器、Office、邮件客户端、IDE、PDF 阅读器等
- 直接读写文件：下载、解压、重命名、组织目录、转换格式
- 自动化重复任务：批量录入、跨系统搬运数据、表格处理、归档
- 编排复杂流程：登录、检索、筛选、导出、填表、通知、记录全过程
- 自托管与隔离：所有操作在容器化桌面中进行，避免泄露与环境污染

## Bytebot 与传统 RPA 的区别

- 更通用：不依赖特定网页或应用的固定 DOM/控件结构，真实地操作桌面
- 更稳健：当界面变化或弹窗出现时，AI 能重新规划并自适应
- 更智能：支持多模型（Claude、GPT、Gemini），理解任务意图与上下文
- 更易用：用自然语言描述目标即可开始，无需复杂脚本

## 自托管的优势

- 隐私与合规：数据在你自己的环境中处理，不外传
- 控制与稳定：可控的依赖与版本，隔离和回滚方便
- 没有配额限制：按需扩容，资源分配自定义
- 安全隔离：容器/进程/网络多重隔离，API 安全策略可配

## 真实场景用例

- 企业自动化：从企业门户抓取数据、汇总报表、回填系统
- 业务流程自动化：生成发票、邮件发送、文件分类与归档
- 开发与 QA：以真实桌面环境进行端到端测试、构建与发布

## 工作方式概览

1. 描述任务：用自然语言告诉 Bytebot 你要完成的目标
2. AI 规划与执行：Agent 选择合适工具，逐步完成任务
3. 观看或放手：可以在 UI 中观察执行过程，也可交给它全自动完成
4. 获取结果：任务完成后，产出文件、报告或状态更新

## 架构组件

- Bytebot Desktop：完整 Ubuntu + XFCE4 桌面，noVNC 提供浏览器访问
- AI Agent：NestJS 服务，集成多家 LLM，通过 WebSocket/REST 驱动桌面
- Task Interface：Next.js Web UI，任务创建与监控、嵌入式 VNC
- REST API：Agent API（9991）与 Desktop API（9990），便于程序化控制

## 关键特性

- 自然语言控制：无需脚本即可发起自动化
- 完整桌面访问：鼠标键盘控制、屏幕截图与 OCR、应用管理
- 完整隐私：自托管，桌面与网络可按需隔离
- 两种模式：Autonomous（自主）与 Takeover（人机协作/接管）
- 直接桌面访问：浏览器即可观看与交互
- 快速部署：Railway 一键、Docker Compose 本地部署
- 友好 API：Agent 与 Desktop API，支持 MCP（Model Context Protocol）
