# 密码与认证管理

Bytebot 支持通过主流密码管理器实现自动化登录与认证流程，包括：

- 1Password
- Bitwarden
- LastPass
- KeePass

支持的认证类型包括：
- 用户名/密码
- TOTP 二次验证（如 2FA）
- 多步认证流程（多页面、多表单）

## 快速开始

<Steps>
  <Step title="选择你的密码管理器">
    在企业或个人环境中选择你偏好的密码管理器（如 1Password）。
  </Step>
  
  <Step title="创建或导入凭据库">
    将网站与应用的登录凭据整理到一个或多个保管库中，并按域名/系统分类。
  </Step>
  
  <Step title="在 Bytebot 中启用">
    通过环境变量或配置文件将密码管理器连接到 Bytebot。确保只授予最低必要权限。
  </Step>

  <Step title="进行登录自动化">
    当任务需要访问受保护系统时，Bytebot 将自动检索对应凭据并完成登录。
  </Step>
</Steps>

## 企业部署指南

### 集中式凭据管理
- 为不同团队与系统建立独立保管库
- 使用角色/组权限控制访问范围
- 对敏感系统开启访问审批流程

### 安全最佳实践
- 最小权限原则：仅提供必需的登录条目
- 审计日志：启用访问与使用日志，定期审查
- 密钥轮换：定期更新密码与 API 密钥，并自动化轮换流程
- MFA 强制：要求管理员与高敏感权限启用多因素认证

## 常见认证场景

### 银行与金融系统
- 多页面登录 + 2FA + 短信或 TOTP
- 建议：将账户分级，并将高风险操作设置审批

### 政府与办事平台
- 复杂的多步表单与验证码
- 建议：使用人机协作（接管模式）辅助首次流程梳理

### 多租户 SaaS 平台
- 子域/租户切换登录
- 建议：为每个租户维护独立条目，避免混淆

## 配置示例

以下为几种常见密码管理器的集成说明。请根据你的环境选择对应方案。

### 1Password
- 使用服务账号或 Token 连接到指定保管库
- 配置访问策略与审计
- Bytebot 在登录阶段读取必要条目（不会存储明文）

### Bitwarden
- 自建或云托管
- 使用只读访问令牌连接
- 配置组织与集合来划分权限

### LastPass
- 为团队创建共享文件夹
- 启用访问日志并定期审计
- 使用最小权限的访问密钥

### KeePass
- 使用加密数据库文件（.kdbx）
- 将只读副本挂载到 Bytebot 运行环境
- 定期同步并轮换主密码

<Warning>
  **敏感数据处理**：Bytebot 不会持久化明文密码，但在自动化登录过程中会读取凭据。请确保运行环境安全，并限制输出日志中出现敏感数据。
</Warning>

## 故障排查

- 登录失败：检查域名匹配、表单字段与凭据条目
- 2FA 无法自动完成：启用 TOTP 并确保时间同步；必要时使用接管模式辅助
- 多步流程断链：使用接管模式演示一次后，Bytebot 将学习路径
- 权限不足：为任务运行主体增加访问权限或申请临时授权

## 总结

通过与密码管理器的集成，Bytebot 能够在保证安全与合规的前提下自动完成各类登录与认证流程，实现企业级的自动化操作。
