# Agent 系统

Agent 是驱动 Bytebot 桌面自动化的 AI 大脑，负责理解任务、规划步骤、选择工具并在执行中自适应与纠错。

## 多模型集成

- 支持 Anthropic Claude、OpenAI GPT、Google Gemini 等
- 可通过 LiteLLM 统一代理使用 100+ 模型与提供商
- 根据任务类型与上下文选择最合适的模型

## 任务管理与生命周期

- 状态：Created → Queued → Running → Needs Help → Completed/Failed
- 属性：描述、优先级、类型、历史消息、产出文件等
- 智能处理：优先队列、错误恢复、人机协作、上下文保持

## 真实能力示例

- Web 自动化：搜索、登录、导航、抓取与下载
- 文档工作：阅读/填写 PDF、整理表格、生成与转换
- 邮件与沟通：读取邮件、整理附件、起草回复
- 数据处理：清洗格式、去重合并、结构化导出

## 技术架构

- NestJS Agent 服务：任务编排与消息系统
- 数据库模式：Prisma + Postgres 持久化任务与消息
- 电脑行动桥：统一 Desktop API，将高层意图映射到具体操作
- API 端点：任务创建/查询/更新、模型列表、WebSocket 消息
- Chat UI：实时交互、视觉反馈、任务管理

## 安全与隐私

- 数据隔离：任务与文件仅在容器内处理
- 访问控制：生产环境建议开启鉴权与网络边界

## 扩展 Agent

- 增加新的工具与动作
- 接入自定义模型或代理
- 根据你的业务流程编写高层策略
